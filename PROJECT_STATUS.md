# Текущий статус проекта

Дата обновления: 11 сентября 2026 года.

## Рабочий результат

Приложение использует только живой поиск. Переключатель демонстрационного режима
удалён, файл с демонстрационными компаниями удалён.

Контрольный запрос «филе куриное, Екатеринбург» в текущей сети завершился за
39,64 секунды и вернул:

- 3 поставщика с подтверждённой товарной позицией и буквальными цитатами;
- 8 кандидатов, в том числе компании с ИНН и историей контрактов;
- 3 успешных LLM-запроса и 8 принятых подтверждённых фактов;
- 2 некритичных предупреждения: один запрос DuckDuckGo не выполнился, а
  дополнительный обход ссылок был остановлен по внутреннему лимиту времени.

Профили производителей ProductCenter проверяются вместе с товарными страницами.
За счёт этого у найденных компаний извлекаются опубликованные ИНН, телефоны,
email, ОГРН и юридические адреса. Реестр контрактов и B2B-каталог запускаются
параллельно, чтобы оставить больше общего 45-секундного бюджета на сайты и LLM.

Результат зависит от текущего состояния внешних сайтов, поэтому числа могут
меняться между запусками.

## Источники

- ProductCenter: открытые товарные карточки российских производителей;
- «Госзатраты»: публичный JSON API контрактов 44-ФЗ/223-ФЗ на основе данных ЕИС;
- Yandex Search API или Brave Search API при наличии ключа;
- DuckDuckGo как необязательный резерв без ключа;
- 2ГИС как отключаемое дополнение для поиска организаций и контактов.

Прямой RSS zakupki.gov.ru выключен по умолчанию: российская TLS-цепочка настроена,
но backend ЕИС часто отвечает HTTP 503. История контрактов продолжает поступать
через «Госзатраты», а карточка содержит ссылку на первоисточник ЕИС.

## Гарантии качества данных

- поисковый сниппет используется только для обнаружения URL;
- факт принимается только вместе с URL и дословной цитатой;
- LLM не выставляет рейтинг и не может сохранить неподтверждённое значение;
- подтверждение отраслевого каталога явно отличается от официального сайта;
- история контракта не считается текущим наличием товара;
- розница, маркетплейсы, соцсети и очевидно другой тип продукта исключаются;
- готовое блюдо (например, запечённое филе) не подтверждает поиск сырого филе;
- сбой отдельного источника не обнуляет выдачу.

## Реализовано

- Gradio-интерфейс, прогресс, таблицы подтверждённых компаний и кандидатов;
- открытие карточки через выбор компании и кнопку;
- сравнение компаний и CSV с цитатами;
- асинхронный загрузчик с robots.txt, лимитами, retry и SQLite-кэшем;
- детерминированное и проверяемое LLM-извлечение;
- нормализация, дедупликация и объяснимый рейтинг;
- миграции SQLite и история запусков;
- изоляция ошибок 2ГИС, ЕИС, каталогов, веб-поиска и отдельных сайтов.
- демонстрационный провайдер, режим и тестовые демонстрационные карточки полностью
  удалены из исходного кода;
- 106 автоматических тестов, Ruff и проверка форматирования проходят.
